# استوديو المراية الذكية وغرفة قياس الملابس الافتراضية (VisionCraft - AR Smart Mirror) 🪞👔

استوديو واقع معزز (AR) ذكي لتجربة وقياس الملابس، الأزياء التراثية، والبدلات الرسمية والأكسسوارات في الوقت الفعلي بسرعة 60 إطار في الثانية وبدقة تشريحية عالية.

## 🌟 المميزات والتقنيات:
1. **تتبع معالم الوجه والجسم (AI Tracking):**
   - تتبع شبكة الوجه (MediaPipe Face Mesh - 468 نقطة).
   - تتبع نقاط الهيكل العظمي للجسم (MediaPipe Pose - 33 نقطة).
   - تتبع اليدين وتفاعلات الإيماءات (Hand Landmarks).
2. **كتالوج الأزياء والتجربة الافتراضية:**
   - بدلات رسمية رجالية ونسائية.
   - أزياء شعبية وتراثية يمنية.
   - قبعات وأرواب تخرج وأوشحة.
   - نظارات شمسية وعصرية.
3. **دعم الكاميرا المزدوجة (Dual Camera):**
   - كاميرا اللابتوب / الكمبيوتر المدمجة (Local Webcam).
   - كاميرا الجوال اللاسلكية عبر شبكة الـ Wi-Fi (IP Webcam).
4. **واجهة زجاجية تفاعلية (Glassmorphism UI):**
   - أرفف تفاعلية ثلاثية الأبعاد (Left Wall, Center Wall, Right Wall).
   - تحكم كامل بالفأرة وبالإيماءات.
   - التقاط وحفظ لقطات عالية الدقة في مجلد `snapshots/`.

---

## 🚀 طريقة التشغيل:

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### 2. تشغيل استوديو المراية:
```bash
python run.py
```
أو تشغيل الملف مباشرة:
```bash
python run_ar_studio.py
```
*(ملاحظة: يمكنك التبديل بين كاميرا اللابتوب وكاميرا الجوال من داخل واجهة البرنامج بالضغط على زر الكاميرا).*
